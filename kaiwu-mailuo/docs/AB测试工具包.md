# 《开物脉络》强基线 A/B 探索性测试工具包

> 对应执行计划 P4。测试性质：**探索性用户测试（8–12 人）**，不做显著性宣称，只回答
> 「缺口感知讲解是否值得作为核心卖点」这一方向性问题。

## 一、测试设计

| 项 | A 组（强基线） | B 组（缺口感知） |
|---|---|---|
| 讲解组织 | 专家固定序列：产业链总览 → 古代火候 → 炼铁炼钢 → 锻打对照 → 连铸轧制 → 天工开物 → 开物谱 | 相同内容池，按规则引擎实时排序：前置缺口 > 叙事连续 > 课程相关，重复与负担做减分 |
| 路线 | 同一条固定安全物理路线（M2→M3→M4→M5） | 同一条固定安全物理路线（物理路线不变，只变讲解内容） |
| 内容质量 | 相同（同一批解释卡） | 相同 |
| 时间预算 | 近似（≤15 分钟） | 近似（≤15 分钟） |

被试：8–12 名同学，按报名顺序交替分配 A/B。全程可用手机完成，模拟现场流程。

## 二、流程（每人约 15 分钟）

1. 主试读引导词（30 秒）：「假设你在一个钢铁工业研学现场，系统会陪你走完四个观察点。」
2. 被试在首页选择「学校研学」，A/B 分组已在选择器中预设。
3. 依次完成：造物问 2 题（自由浏览 2 分钟）→ 现场 M2/M3/M4/M5（观察 + 轻互动）→ 追问 1 个问题 → 开物谱。
4. 主试记录用时；被试立即填问卷。

## 三、测量（对应文档冻结的指标）

**理解（客观）**
- 流程结构：请把「炼铁 / 炼钢 / 连铸 / 轧制 / 铁矿石采选」按生产先后排序（5 空，1 分/空）
- 工艺因果：1 道因果题（为什么高炉出来的还要炼钢？三选一）
- 近迁移：1 题（连铸出来的钢坯能直接轧钢板吗？为什么？）

**体验（主观，5 级李克特）**
- 时间效率：完成用时（客观记录）
- 认知负荷：单题「刚才的过程需要动脑的程度」（1=很轻松，5=很吃力）
- 考试感：单题「我觉得自己一直在被考试」
- 分心感：单题「手机让我少看了现场」
- 自主感：单题「我觉得系统在跟着我走，而不是我在跟着系统走」

**系统日志（自动）**
- 各任务首答正确率、断点出现与解除次数、解释卡曝光与展开率

## 四、死亡条件（预先注册，防止硬保错误假设）

若 B 组出现以下任一情形，则把「实时自适应」从核心卖点降级为「可选能力」，展板改以
「古今造物问题可交互 + 课程衔接」为主卖点：
1. 流程结构/因果/近迁移得分中两项低于 A 组；
2. 「考试感」「分心感」均值高于 A 组 1 分以上；
3. 用时显著长于 A 组且正确率无优势。
