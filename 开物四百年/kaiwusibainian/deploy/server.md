# 开物四百年 · 完整版上线指南（云服务器 · 主路线）

> 结论：COS+CDN 教程（见同目录 README.md）**只能托管静态文件**。
> 要带「问个开物」问答、教师端数据的**完整版**，需要一台小服务器。
> 本项目部署条件极好：`uvicorn` 单进程同时服务 API 和 `frontend/dist`，SQLite 启动自动建库，服务器只需要 Python。

## 两条路线

| | 路线 A：IP 直访 | 路线 B：域名 + HTTPS（推荐展板用） |
|---|---|---|
| 网址 | `http://<IP>:8100` | `https://www.你的域名` |
| 域名 | 不用买 | 要买（成品域名 ¥7-8/年起） |
| 备案 | 不需要（服务器在香港） | 不需要（服务器在香港） |
| HTTPS | 无（HTTP） | 有，Caddy 自动申请续期证书 |
| 上线耗时 | 买完服务器约 10 分钟 | 多花域名解析等待 5 分钟~几小时 |
| 指南 | `deploy/DEPLOY.md`（已备好） | 本文档 |

赶进度选 A（随时可升级 B）；展板二维码要体面选 B。

## 先澄清一个概念

没有「香港域名」这回事——香港指的是**服务器节点**，境外节点域名就不用备案。
域名随便买：`.com` / `.top` / `.xyz` 成品域名（¥7-8/年）都行。

## 你的清单（控制台操作，按顺序）

- [ ] **1. 实名认证**：账号中心 → 实名认证 → 个人认证（身份证 + 人脸，一般当天通过）。买服务器/域名的共同前提

  | 套餐 | 2核2G 最低档 | 2核2G 最低档 |

- [ ] **3.（仅路线 B）买域名 + 解析**：DNS 控制台加两条 A 记录，`@` 和 `www` → 服务器公网 IP

## 我来做的部分（路线 B；路线 A 你自己照 DEPLOY.md 也能走完）

1. ssh 连机：装 caddy
2. 本地 `npm run build` → 打包上传（自动排除 `app.db` / `local_settings.py`）
3. systemd 常驻：`python -m uvicorn main:app --host 127.0.0.1 --port 8100`
   （改自 `deploy/kaiwu.service`：只绑定本机，由 Caddy 对外；开机自启、崩溃自动拉起）
4. `/etc/caddy/Caddyfile` 两行反代，域名解析一生效证书自动签发：

   ```
   www.你的域名 {
       reverse_proxy 127.0.0.1:8100
   }
   ```

5. 防火墙：路线 A 放行 TCP 8100；路线 B 放行 80/443（**不要**再开 8100）
6. `python seed.py` 灌库，三模式 + 问答 + 教师端全流程验证，生成高清二维码

## 与本地版的差异（提前知道）

- 服务器上 `app.db` 是全新库（首次启动从 `content.json` 自动建库灌数据）
- 「问个开物」消耗 DeepSeek token，公开访问量大时留意余额；比赛结束可清空密钥行关掉 AI（自动降级本地知识库）
- 公网上谁都能访问教师端和信号接口 → 上线后建议加一个极简口令门（几分钟的事）
- 域名解析生效 5 分钟 ~ 48 小时；Windows 验证：`nslookup www.你的域名`
- 评审前一周用手机流量完整走一遍，确认服务器流量/密钥余额充足
